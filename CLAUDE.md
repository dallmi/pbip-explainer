# CLAUDE.md – pbip-explainer

Skill + stdlib Python tool that turns a PBIP project (zip/folder) into a knowledge pack and documentation. Language: English everywhere (code, docs, skill).

## Layout

- `skills/pbip-explain/SKILL.md` – agent playbook (< 200 lines); details in `references/`
- `skills/pbip-explain/scripts/pbip_explain.py` – CLI; package `pbipx/`
- `.claude/skills/pbip-explain` – symlink so Claude Code loads the skill in this repo
- `examples/` – synthetic PBIP projects, generated by `examples/generate_examples.py`. Edit the generator, not the files
- `app/` – desktop UI: `server.py` (stdlib web server on 127.0.0.1, JSON API, runs in `work/ui-runs/`) and `static/index.html`; started by `start.bat` / `start.command`
- `single-file/pbip_explainer.py` – generated one-file edition for copy-paste installs; rebuild with `scripts/build_single_file.py`, never edit by hand
- `tests/test_pbipx.py`, `test_app.py`, `test_package.py`, `test_single_file.py` – unittest, stdlib only
- `work/` – git-ignored scratch for real projects
- `copilot/` – Copilot Studio instructions (mode A Q&A, mode B code execution) and `notes/` inserted into the packaged `SKILL.md`; `scripts/build_copilot_skills.py` builds `dist/copilot/` (git-ignored)

## Rules

- **Stdlib only, Python 3.9+.** The tool must run on a locked-down work PC. No f-string expressions with backslashes (3.9).
- **Docs stay self-contained**: no CDN, no external fonts or scripts in the HTML. A test checks this. Same for `app/static/index.html`.
- **App security**: bind 127.0.0.1 only; keep the Host check, the `X-PBIPX` header + Origin check on POST and the path checks on file serving (`tests/test_app.py` covers them).
- **Never guess.** Extracted facts, pattern-based descriptions (`auto`) and agent text (`AI-drafted`) stay visibly separate.
- **No data, no personal data**: skip `*.abf` caches, never extract RLS member names, no real projects in `examples/` or tests.
- Colours and type follow `Arbeit/00-design-system/` (white dominates, warm greys, red only as accent).
- New Power BI quirk found on a real project → fix + regression case in `generate_examples.py` and `tests/`.
- **Copilot Studio:** deviations go into `copilot/`, never into `skills/`. The skill package may hold at most 20 files besides `SKILL.md` (now 17): a new `pbipx` module counts. Renamed or added knowledge files → update `KNOWLEDGE_FILES` in the build script and the file table in `copilot/agent-instructions-qa.md` (a test checks both).
- **Agent Builder package**: knowledge files are .docx (Agent Builder and Copilot Studio do not read Markdown from SharePoint), stable file names, model name in every heading, at most 100 files per agent.
- New `pbipx` module → add it to `MODULE_ORDER` in `scripts/build_single_file.py` (the build stops otherwise).
- Knowledge schema change → bump `KNOWLEDGE_SCHEMA_VERSION` in `pbipx/__init__.py` and update `references/knowledge-schema.md`.
